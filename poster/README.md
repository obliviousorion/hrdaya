# A3 poster

`poster.tex` is an A3 landscape scaffold, not final content. Complete it from the shared
report metrics/figures; use the supplied template in sources/ for visual guidance.
From this folder: `pdflatex poster.tex` (TeX installation required separately).
Convert generated SVGs to PDF with a vector editor before including them in LaTeX.
Proof at actual A3 size, verify QR and all report/poster numbers, then arrange colour printing.
