\section*{\color{primary} Problem \& Objectives}
Traditional modalities (face, fingerprints) lack inherent vitality guarantees and are vulnerable to spoofing.
Electrocardiogram (ECG) waveforms provide \textbf{intrinsic liveness} and person-specific cardiac morphology.
\begin{itemize}
    \item \textbf{Target:} Edge microcontrollers / embedded Linux ($\le 100\text{ KB}$ memory, $\le 1\text{ ms}$ latency).
    \item \textbf{Evaluation Benchmark:} Open ECG-ID Database v1.0.0 (89 usable subjects, 7,875 segmented beats).
    \item \textbf{Protocol:} Strictly recording-disjoint split (final recording held out for testing; no beat leakage).
\end{itemize}

\section*{\color{primary} Proposed Pipeline}
\begin{enumerate}
    \item \textbf{Preprocessing:} 4th-order zero-phase Butterworth bandpass filter (0.5--40.0 Hz).
    \item \textbf{R-Peak Detection \& Segmentation:} 300-sample beat windows (0.6 s window: 0.2 s pre-R to 0.4 s post-R), z-score normalized.
    \item \textbf{On-the-Fly Augmentation:} Random temporal roll ($\pm 8$ samples), amplitude scale ($\pm 10\%$), Gaussian noise ($\sigma=0.01$).
    \item \textbf{Architecture (\texttt{ECG\_ResNet\_SE}):}
    \begin{itemize}
        \item 1D-ResNet with depthwise-separable convolutions.
        \item Squeeze-and-Excitation (SE) channel attention for QRS complex vs.\ P/T-wave reweighting.
        \item 48-dimensional latent biometric embedding.
    \end{itemize}
    \item \textbf{Hybrid Loss Function:}
    $$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CrossEntropy}} + 0.5 \cdot \mathcal{L}_{\text{ArcFace}}$$
    Optimizes simultaneously for 1:N Identification and hyperspherical metric clustering for 1:1 Verification.
    \item \textbf{Dynamic INT8 Quantization:} Post-training 8-bit dynamic integer weights.
\end{enumerate}

\section*{\color{primary} Offline Replay Prototype}
\begin{itemize}
    \item Implemented in \texttt{scripts/demo\_replay.py}.
    \item Evaluated against enrolled training templates using cosine similarity with a fixed threshold ($\cos \theta \ge 0.50$).
    \item \textbf{Result:} \textbf{97.8\% Genuine Accept Rate (87/89 subjects)} successfully authenticated.
    \item Real-time batch-1 inference: \textbf{0.62 ms} (p95: 1.06 ms) on commodity CPU.
\end{itemize}

\section*{\color{primary} Summary \& Edge Viability}
\begin{itemize}
    \item \textbf{High Biometric Accuracy:} Cuts baseline verification error by 66\% (13.11\% $\to$ 4.50\% EER) and delivers \textbf{95.51\%} 5-beat identification.
    \item \textbf{Minimal Footprint:} Fits inside \textbf{66.3 KB} of storage, enabling deployment on resource-constrained microcontrollers.
    \item \textbf{Zero Retraining Loss:} Dynamic INT8 quantization preserves accuracy and verification EER with zero degradation.
\end{itemize}
