## Big-Picture Goal

Build a system that authenticates people using their ECG (heart-beat waveform) as a biometric, compare a classical signal-processing baseline with an LSTM and a compact 1-D CNN, evaluate everything for edge deployment (Raspberry Pi / INT8), and deliver:

1. A written **report** (following a supplied DOCX template)
2. An **A3 colour poster** (LaTeX scaffold included)
3. A **running prototype** that can do offline ACCEPT/REJECT replay

## Core Pipeline — How the Code Works

### 1. Data ingestion — `src/mlee/baseline.py :: read_record()`

Reads **WFDB format-16** `.hea` / `.dat` pairs directly (no `wfdb` dependency).
Validates: exactly 2 channels, 500 Hz sample rate, int16 encoding.
Returns: raw millivolt signal (channel 0 only), sample rate, comment lines (age/sex/date), header time fields.

### 2. Beat segmentation — `src/mlee/baseline.py :: segment()`

```
Raw signal (ch 0)
  → 4th-order Butterworth bandpass 0.5–40 Hz (zero-phase, sosfiltfilt)
  → Derivative² smoothed over 100 ms window  →  energy envelope
  → find_peaks() with distance ≥ 350 ms, prominence threshold
  → Refine each peak to max |signal| in ±120 ms window
  → Clip: only peaks not too close to signal edges (200 ms left, 400 ms right)
  → Extract 0.6 s window (200 ms before R, 400 ms after R)
  → Z-score normalise each beat; discard if std < 1e-8
```

Output: `(N_beats × 300)` array.

### 3. Feature extraction — `src/mlee/baseline.py :: features()`

For each 300-sample beat:
1. Full autocorrelation → one-sided (length 300)
2. Normalise AC by AC[0]
3. Apply DCT-II (ortho norm)
4. Take coefficients **1–32** (drop DC)

Output: `(N_beats × 32)` feature matrix.

### 4. Train/test split — inside `run()`

- Collect all `.hea` files, group by `Person_*` folder.
- Sort each person's recordings by numeric suffix.
- **Last usable recording** → test set; all earlier → train.
- Persons with < 2 usable records → excluded (only `Person_74` currently).
- **Recording-disjoint**, not guaranteed cross-day (dates not fully audited).

### 5. Classification — `run()`

```python
Pipeline: StandardScaler() → SVC(C=10, kernel='rbf', gamma='scale')
```

Trained on 5,587 beats from 89 identities; tested on 2,288 beats.

### 6. Verification — `run()`

Independent of SVM. Cosine similarity between:
- Enrollment templates = per-class mean of `StandardScaler`-transformed training features
- Test beats (also transformed)

EER computed by interpolating FAR/FRR crossover on the ROC curve.

### 7. Output — `run()` → `details.json` (ignored by git) + `metrics.json` (tracked)

`metrics.json` contains only the compact public numbers.
`details.json` (local only) also contains full confusion matrix, split manifest, exclusions.

## Experiment Harness — `src/mlee/experiments.py :: execute()`

Every experiment run:
1. Reads and validates the YAML config (fields: `experiment`, `seed`, `data`, `method`, `protocol`)
2. Seeds `random` and `numpy.random`
3. Creates `results/<experiment>/<UTC-timestamp>/` directory
4. Saves a `run.json` with git hash, tree hash, dirty flag, source SHA-256s — provenance-first
5. Calls `baseline.run()` (currently the only registered method/protocol)
6. On success: writes `metrics.json`, updates `run.json` status → `"complete"`
7. On failure: writes error to `run.json`, re-raises (failed runs stay in directory for diagnosis)
8. Caller (`run_experiment.py`) then calls `leaderboard.generate()` to refresh `LEADERBOARD.md`

> [!NOTE]
> The dispatcher in `experiments.py` deliberately raises `ValueError` for any
> `method` or `protocol` other than `ac_dct_svm_frozen` / `last_usable_record`.
> New models must be registered here before they can be run.
